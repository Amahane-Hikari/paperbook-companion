# 开发路线

P0/P1 下的勾选表示**实现已接入且有本地或受控验证**，不表示真实服务、质量、完整浏览器矩阵或比赛指标已验收。继续工作以[功能状态](FEATURE_STATUS.md)和[验证记录](VALIDATION.md)为准；业务主线在 `app/`，冻结参考不改。

## P0：主流程实现与本地验证

- [x] **P0-1 统一入口、配置与能力状态。** 新工作台接 `/` 和 `/books`，旧主题页保留；配置模板不含可用凭据，能力接口只做配置/本机检查。已有本地 Flask 路由与默认无凭据验证；目标机器安装和真实网络可用性仍需复核。

- [x] **P0-2 接入 PDF 导入与阅读。** fast/auto/full、复核选项、逐页原图及明确失败状态已实现，受控浏览器完成三页混合 PDF 导入与原图阅读。真实 OCR/视觉识别质量未验收。

- [x] **P0-3 保留稳定页标识。** 文字、扫描页和无字页使用原页号，不过滤空页；完整模式包含无字页视觉/物体处理。本地真实 PDF 用例覆盖混合页与错误状态。

- [x] **P0-4 修复失败处理与结构解析。** Agent 有预算和明确异常，移除模型文本直接求值；OCR 空白、未知结构及错误引用被拒绝。已做本地回归；真实提供方的异常与超时分布待测。

## P1：生成与互动实现、本地/受控验证

- [x] **P1-1 连接页级媒体与持久任务。** 原页图接视频适配器，真实 WAV 测时、缓存、force、失败、重试和重启中断状态已实现。受控浏览器走通媒体失败重试；真实视频模型未验收。

- [x] **P1-2 合成配音整片。** 全本 PCM 一次拼接编码、H264/AAC、独立字幕及时间轴 v2 已实现。真实 FFmpeg 与20页非整帧时长探针确认末页画面/配音保留；受控浏览器走通导出。模型画质及成片主观质量待测。

- [x] **P1-3 接入原文依据与会话历史。** 关键词/bigram、有限指代历史、合法页引用与媒体引用落盘已实现；受控浏览器走通带引用问答。本地覆盖会话并发与恢复接口；浏览器刷新/附件验收继续补充。通用视频语义与图片附件理解尚不能据此宣称完成。

- [x] **P1-4 统一点读坐标与上下文检查。** 显式像素契约、contain 留黑处理、迟到响应失效及播放恢复条件已实现，纯函数测试已通过。真实浏览器点读、竞态与恢复矩阵仍需完成，真实视觉模型命中质量待测。

- [x] **P1-5 接入单页速读和拍照页图入库。** 保留整本 PDF 工作台，提供单页预览、生成、点读和问答，以及单页／有序多页照片入库。真实供应商与扫描页的识别质量仍需验收。

## P2：质量、时延和交付验收

- [ ] **P2-1 完成真实服务和浏览器矩阵。** 在用户配置的服务上核对 OCR、视觉、视频、TTS/ASR 和问答契约；覆盖麦克风权限、自动播放拒绝、切书/切页/seek 竞态、取消、恢复与附件。验收：记录真实环境、输入、结果和失败恢复，不能用受控输出替代。

- [ ] **P2-2 测量并改善真实首音时延。** 记录语音结束、识别完成、模型首输出及实际音频首播时间，分别报告冷启动与稳定状态；按能力安排预热与流式处理。验收：真实浏览器全链时延、失败率和正确率同时报告。

- [ ] **P2-3 建立多绘本质量评测。** 覆盖扫描、无字页、不同版式；评估回答正确性、依据一致性、视频内容定位、点读命中和页间/角色/画风连贯。验收：固定测试集、逐项结果和可核对证据，目标值先与正式规则核对。

- [ ] **P2-4 补齐任务所需语义能力。** 根据实际要求补充超出关键词匹配的视频语义检索及图片附件理解，并保留来源与时间定位。验收：区分“记录媒体引用”和“理解媒体内容”，无依据不答，检索与回答分开测量。

- [ ] **P2-5 完成可复核交付。** 固定依赖/模型与配置版本，整理关键提示词、素材/工具来源、内容审核、演示视频和项目说明。验收：另一台目标机器用新输入复现，媒体格式与项目材料符合已核实要求；明确保留所有未验收限制。

百科、试卷、音色克隆与额外音乐效果排在核心验证之后。后续 PR 同步更新[功能状态](FEATURE_STATUS.md)、[验证记录](VALIDATION.md)及涉及的[书本 API](BOOK_API.md)。
