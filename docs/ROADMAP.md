# 开发路线

以下条目均待完成，可按编号认领并建立分支/PR。业务修改只进入 `app/`；`reference/pdf-import/` 保持冻结，按功能移入。先修复阻断，再补生成与交互闭环，最后完成性能和交付验收。当前状态见[功能状态](FEATURE_STATUS.md)。

## P0：可靠进入主流程

- [ ] **P0-1 统一入口、配置和能力状态。** 保留共享版前缀中间件与语音/视频适配，补全配置模板；未配置能力和可选音乐/音效失败应明确降级。验收：新环境依说明启动，页面与 API 路径一致，无 404 或假成功；能区分服务存活与各能力可用。

- [ ] **P0-2 集成 PDF 上传与阅读。** 移入并修复 PDFReader、路由和界面；打通 mode 传递，消除未定义渲染/音频函数；文字层为空时提供 OCR 路径。验收：文字型和扫描型 PDF 均能进入阅读，逐页结果和失败状态可核对，TTS 确实启动。

- [ ] **P0-3 建立稳定页标识。** 保留 page_id/page_num，使文字、原图、物体和媒体引用不依赖过滤后的数组下标；无字页也处理画面与物体。验收：封面、连续无字页和中间空页均不造成配图/物体错位，来源页可定位。

- [ ] **P0-4 修复模型调用与结构解析。** 重试具有次数和时间预算，首次异常可恢复，调用参数一致；用 JSON/安全字面量与类型校验替换 eval。验收：请求异常、结构错误和章节失败均在预算内结束，返回明确状态，不执行模型文本。

## P1：生成与互动闭环

- [ ] **P1-1 从指定绘本生成页级视频。** 连接 PDF 数据与现有视频任务链，优先复用原页图；统一任务状态、缓存、失败重试和生成记录。验收：换一本绘本即可自动生成各页媒体，无需人工制作插图或修改 JSON，保留原页映射。

- [ ] **P1-2 合成跨页配音整片。** 按实际 TTS 时长对齐视频，拼接全部页、混入音轨并生成字幕及页/句子时间轴。验收：输出独立可播放的视频文件，自动核对时长、音轨、分辨率、帧率和顺序；网页之外也能播放完整内容。

- [ ] **P1-3 实现有依据的问答与历史。** 接入绘本原文、当前页/帧/视频时间和会话历史；支持内容与时间段检索，持久化文本及语音/图片引用。验收：书中事实、当前页、人物与跨轮追问均能定位依据；刷新后可恢复同一会话，缺乏依据时明确表达。

- [ ] **P1-4 统一点读坐标与恢复播放。** 声明坐标单位、参考尺寸和来源帧，去掉按数值范围猜格式的逻辑。验收：原图、视频帧、不同缩放及留黑布局下命中正确；朗读标签后可恢复阅读，不复用错误页/帧缓存。

## P2：性能、质量与交付验收

- [ ] **P2-1 测量并改善真实首音时延。** 解除等待全部素材后播放的阻塞，按能力接入流式识别/回答/语音并预热模型。验收：记录语音结束、识别完成、模型首输出、实际音频首播时间，分别报告冷启动与稳定状态，并保留失败率和正确率。

- [ ] **P2-2 固定环境与多绘本评测。** 记录依赖、模型、服务契约和配置版本，建立包含扫描页、无字页、不同版式的测试集。验收：真实服务和浏览器完整流程可重现，覆盖回答正确性、检索定位、点读命中、画风/角色一致性与页间连贯；目标值依据正式规则核对后记录。

- [ ] **P2-3 完成可复核交付。** 整理启动说明、关键提示词、素材/工具来源、内容审核记录、演示视频与项目说明。验收：他人按文档在新环境运行并用新输入复现，最终媒体和项目材料符合已核实的交付要求，已知限制清楚列出。

百科、试卷、音色克隆和额外音乐效果保留为后续能力，排在上述核心闭环之后。勾选条目时，同时更新[功能状态](FEATURE_STATUS.md)与[验证记录](VALIDATION.md)，附对应验证证据。
