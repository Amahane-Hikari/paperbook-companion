## 关键复现结果

- Agent 结构校验失败时，`max_try=2` 仍进入第 6 次替身请求，测试主动终止；首次请求异常触发 `UnboundLocalError`；章节重试的 `seed` 参数触发 `TypeError`。
- 对模型输出的列表解析会执行表达式；隔离测试使用无害探针确认，应替换 eval。
- 864×480 帧上的绝对像素框 `[100,100,600,400]` 被前端改成 `[86,48,518,192]`。
- 仅返回一个 SSE error 事件时，前端生成函数仍正常 resolve，进入等待零章视频和尝试播放第零页的路径。
- PDF 请求即使带 `mode=full`，入口仍使底层收到 fast；带无字页的数据可使正文与前一页图像错配。

对应源码位置见[功能状态与已知断点](FEATURE_STATUS.md)。这些探针使用替身请求、DOM或抽取的原函数，没有调用真实模型 API。
