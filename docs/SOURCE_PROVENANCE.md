# 源码来源与快照边界

本仓库从 2026-11-15 提供的两个源码包建立协作基线，首次导入没有合并或修复业务代码。

| 原始代码包 | 仓库位置 | 用途 |
| --- | --- | --- |
| `纸书智伴-共享版.zip` | [`app/`](../app/) | 后续协作开发的主基线，包含已有接口兼容、语音和视频服务适配 |
| `tts_book.zip` | [`reference/pdf-import/`](../reference/pdf-import/) | PDF 功能分支的原始参考代码，冻结保留，尚未合入主基线 |

导入的是两包顶层源码、HTML、依赖说明、启动脚本和示例配置。两个版本共用的文件保留在各自目录，便于逐项比较，不表示 PDF 功能已经合并。

首次导入的逐文件 SHA-256 和原始代码包 SHA-256 见 [`source-manifest.json`](source-manifest.json)。该清单用于核对首次快照；后续 `app/` 的正常开发变更通过 Git 历史追踪，不应为了匹配初始哈希回退代码。

## 未纳入版本控制的内容

- 真实 `.env`、凭据和机器专用配置。
- 绘本 PDF、图片、语音、视频和模型权重。
- 生成输出、缓存、聊天导出及带本机路径的运行书架索引。

`bookshelf.json` 不随仓库提交；代码中已有文件不存在时返回空书架的逻辑。已有样例素材由团队成员在自己的授权开发环境中保管和验证，不用于证明本仓库已经自动生成过完整绘本。

本仓库没有额外授予开源许可证。第三方参考代码、依赖和赛事素材的来源及许可边界需要按其原有约定保留和确认；仓库可见性不构成版权授权。
